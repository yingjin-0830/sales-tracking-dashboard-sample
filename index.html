How it works

The dashboard holds no hand-typed numbers. It is computed from the tracker, so the two never drift apart.

SourceTracker in Google SheetsOne row per unit, with the same fields and the same status values in every project. Sales updates happen here and nowhere else.
Roll-upFormulas by project and statusCounts and sums read the status column directly, so units and total values are recalculated whenever a row changes.
OutputDashboardUnit counts and total values by project and sales status, plus the monthly view of each project.

This page recreates the dashboard layer with sample data: every figure above is calculated in your browser from the unit rows in the table, the same way the live version reads the tracker.

All project names, units, prices and dates on this page are sample data generated for demonstration. Prices are contract prices for signed units and list prices otherwise. Closing dates for units that have not closed are targets. Data as of —.
